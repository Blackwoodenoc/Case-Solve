## 2. Технологии проекта

### Нейросети и AI
- **Google Gemini 2.0 Flash Exp** — мультимодальный анализ видео (компьютерное зрение + NLP)
- **Google Gemini 2.5 Flash** — продвинутый анализ коротких видео с извлечением транскриптов
- **OpenAI Whisper** — точная транскрипция речи из видео (модель base)

### Backend технологии
- **Node.js + Express** — серверная часть (порт 3003)
- **Python 3.8+** — скрипты для работы с видео и комментариями
- **yt-dlp** — извлечение видео и метаданных с YouTube, Instagram, TikTok
- **Whisper CLI** — транскрипция аудио через командную строку

### Frontend технологии
- **React 19** — современный UI фреймворк
- **TypeScript** — типизированный JavaScript для надежности
- **Vite** — быстрая сборка и разработка
- **Tailwind CSS** — utility-first CSS фреймворк
- **Lucide React** — современные иконки

### API и интеграции
- **Google Gemini API** — основной AI-сервис
- **Google Search Grounding** — верификация метрик через поиск
- **OEmbed API** — получение метаданных постов (noembed.com)

### Библиотеки и инструменты
- **@google/genai** — официальный SDK для Gemini
- **react-markdown** — рендеринг Markdown в UI
- **cors** — обработка CORS запросов
- **dotenv** — управление переменными окружения
- **concurrently** — параллельный запуск frontend и backend

### Базы данных
- **Файловая система** — временное хранение видео и метаданных (temp_videos/)
- **JSON файлы** — структурированное хранение Style Passports и сценариев

### DevOps
- **Git** — система контроля версий
- **npm** — менеджер пакетов Node.js
- **pip** — менеджер пакетов Python

## 4. Что сделали, как и почему

### Что сделали
Разработали **VideoMind AI** — платформу для глубокого анализа видео с помощью AI, которая:
- Анализирует видео через компьютерное зрение и NLP
- Извлекает "ДНК успеха" из коротких видео (Shorts/Reels/TikTok)
- Генерирует "Паспорт стиля" автора в структурированном JSON формате
- Создает посекундные сценарии новых видео на основе стиля автора
- Поддерживает анализ через загрузку файлов или ссылки на YouTube/Instagram/TikTok

### Как сделали
1. **Архитектура**: Разделили на frontend (React + Vite) и backend (Node.js + Express) для масштабируемости
2. **AI интеграция**: Используем Gemini 2.0/2.5 Flash с мультимодальными возможностями для анализа видео и текста одновременно
3. **Транскрипция**: Интегрировали Whisper для точной транскрипции речи, что критично для анализа tone of voice
4. **Анализ кадров**: Gemini анализирует ВСЕ кадры последовательно (не только ключевые), что дает максимальную детализацию
5. **Структурированный вывод**: AI генерирует строго структурированный JSON с валидацией для надежности

### Почему именно так
- **Gemini вместо других моделей**: Нативная поддержка видео/аудио без предварительной обработки, высокая точность мультимодального анализа
- **Последовательный анализ кадров**: Ключевые кадры могут пропустить важные паттерны, полный анализ дает 100% покрытие
- **JSON формат**: Стандартизированный выход для интеграции с другими инструментами и автоматизацией
- **Whisper для транскрипции**: Более точная транскрипция по сравнению с Gemini-встроенной, особенно для русского языка
- **Разделение frontend/backend**: Позволяет масштабировать, легко добавлять новые API endpoints, независимое развертывание

## 5. Ключевые функции

### 5.1. Стандартный анализ видео
**Описание**: Базовый анализ загруженного видео или ссылки
- Краткое содержание
- Глубокий анализ (объекты, люди, действия с таймкодами)
- Извлечение кода/технического текста
- Анализ удаленных ссылок (YouTube/Instagram/TikTok) с метаданными

**Технологии**: Gemini 2.0 Flash, OEmbed API, Google Search Grounding

### 5.2. Shorts DNA Analysis (Киллер-фича)
**Описание**: Деконструкция коротких видео и извлечение "ДНК успеха" автора
- Анализ структуры видео (Hook → Setup → Main → Climax → CTA) с точными таймкодами
- Извлечение паттернов удержания внимания (крючки, клиффхэнгеры, открытые петли)
- Анализ Tone of Voice (архетип, настроение, формальность, сигнатурные фразы)
- Анализ скорости речи (WPM, темп, стиль пауз)
- Визуальный стиль (монтаж, типы кадров, текст на экране, типичные действия)
- Правила генерации (8-15 конкретных правил для репликации стиля)
- Генерация интерактивного "Паспорта стиля" в JSON

**Технологии**: Gemini 2.5 Flash, Whisper (транскрипция), мультимодальный анализ

### 5.3. Генерация сценариев на основе Паспорта стиля
**Описание**: Создание посекундных сценариев новых видео в стиле автора
- Пользователь вводит только тему (например: "Обзор нового iPhone")
- Система генерирует посекундный сценарий с кадрами и текстом
- Строгое соблюдение стиля автора (инсайты из паспорта)
- Визуальный контекст (описание что происходит в кадре через компьютерное зрение)
- Вывод: JSON с сегментами [00:00-00:05], [00:05-00:15] и т.д.

**Технологии**: Gemini 2.0 Flash, Паспорт стиля как промпт, валидация правил

### 5.4. Извлечение комментариев
**Описание**: Получение комментариев с платформ для анализа
- YouTube: через yt-dlp
- Поддержка сортировки (top/newest)
- Форматирование и структурирование данных

**Технологии**: yt-dlp, Python скрипты

### 5.5. Загрузка и обработка видео
**Описание**: Скачивание видео с платформ для локального анализа
- Поддержка YouTube, Instagram, TikTok
- Извлечение метаданных (просмотры, лайки, описание)
- Автоматическая очистка временных файлов

**Технологии**: yt-dlp, Express API endpoints

## 6. Киллер-фича

### 🧬 Shorts DNA Analysis + Генерация сценариев

**Почему это киллер-фича:**
1. **Уникальность**: Никто не делает такой глубокий анализ коротких видео с извлечением "формулы успеха"
2. **Практическая ценность**: Контент-мейкеры получают готовую "формулу" для создания вирусного контента
3. **Автоматизация**: От анализа до готового сценария — полностью автоматизированный пайплайн
4. **Точность**: Анализ ВСЕХ кадров последовательно + точная транскрипция через Whisper = максимальная детализация
5. **Готовый продукт**: Не просто анализ, а готовые сценарии с посекундной разбивкой и визуальным контекстом

**Как это работает:**
1. Пользователь загружает успешное короткое видео
2. AI анализирует все кадры + транскрибирует речь
3. Система извлекает паттерны, структуру, стиль речи, визуальные элементы
4. Генерируется "Паспорт стиля" — JSON с полной формулой успеха
5. Пользователь вводит тему нового видео
6. AI генерирует посекундный сценарий, строго соблюдая стиль из паспорта
7. Результат: готовый к съемке сценарий с кадрами и текстом

**Конкурентное преимущество:**
- Другие инструменты делают только базовый анализ или генерацию без контекста стиля
- Мы объединяем анализ + генерацию с гарантией соответствия стилю автора
- Визуальный контекст через компьютерное зрение — уникальная фича
