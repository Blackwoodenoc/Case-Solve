# 🚀 Quick Start Guide: Shorts DNA Analysis

## 5-минутное руководство для начала работы

### 📋 Что вы получите
После выполнения этих шагов у вас будет работающее приложение для анализа коротких видео с извлечением "ДНК успеха" и генерацией JSON паспорта стиля.

---

## Шаг 1: Установка (30 секунд)

```bash
# Клонируйте проект (если ещё не сделано)
cd Wub

# Установите зависимости
npm install
```

---

## Шаг 2: Настройка API ключа (1 минута)

1. Получите Gemini API ключ:
   - Перейдите на https://ai.google.dev/
   - Войдите с Google аккаунтом
   - Создайте API ключ (требуется платный GCP проект)

2. Создайте файл `.env.local`:
```bash
GEMINI_API_KEY=ваш_ключ_здесь
```

---

## Шаг 3: Запуск (10 секунд)

```bash
npm run dev
```

Откройте http://localhost:5173 в браузере.

---

## Шаг 4: Первый анализ (3 минуты)

### 4.1 Подготовьте видео
- Короткое видео (15-60 секунд)
- Форматы: MP4, MOV, WEBM
- Тип: Shorts, Reels, TikTok
- Желательно: с чёткой речью и динамичным контентом

### 4.2 Загрузите видео
1. Нажмите кнопку **"Choose File"** или перетащите файл
2. Дождитесь превью

### 4.3 Запустите анализ
1. Прокрутите до секции **"Intelligence Toolbox"**
2. Нажмите кнопку **"🧬 Shorts DNA Analysis"**
3. Дождитесь завершения (20-60 секунд)

### 4.4 Изучите результат
Вы увидите интерактивный **Style Passport** с секциями:
- 📊 **Summary** — общая характеристика стиля
- 💬 **Tone of Voice** — архетип, настроение, формальность
- ⏱️ **Speech Pace** — темп речи (WPM)
- 🎬 **Structure** — таймлайн с hook → climax → CTA
- ⚡ **Retention Patterns** — крючки и клиффхэнгеры
- 🎨 **Visual Style** — монтаж и типы кадров
- ✅ **Do/Don't** — что делать и чего избегать
- 🧬 **Generation Rules** — 8-15 правил для репликации стиля

---

## Шаг 5: Экспорт и использование (30 секунд)

### Скачать JSON
1. Нажмите иконку **Download** в правом верхнем углу паспорта
2. Файл сохранится как `style-passport-{timestamp}.json`

### Скопировать JSON
1. Нажмите иконку **Copy** в правом верхнем углу
2. JSON будет в буфере обмена

### Использовать для генерации
1. Откройте `EXAMPLE_USAGE.md`
2. Скопируйте промпт для LLM
3. Вставьте правила из вашего паспорта
4. Сгенерируйте новый сценарий в том же стиле

## 🐛 Troubleshooting

### "API_KEY_INVALID"
**Проблема:** Неверный или неактивный API ключ  
**Решение:** 
1. Проверьте `.env.local`
2. Убедитесь, что у ключа есть доступ к Gemini API
3. Проверьте биллинг в GCP

### "Shorts DNA Analysis недоступен"
**Проблема:** Кнопка disabled  
**Решение:** Функция работает только с локальными файлами, не с URL

### "JSON невалидный"
**Проблема:** Модель вернула невалидный JSON  
**Решение:**
1. Попробуйте другое видео (более чёткое, на русском/английском)
2. Убедитесь, что в видео есть речь
3. Видео не должно быть слишком длинным (>2 мин)

### Медленная обработка
**Проблема:** Анализ занимает >2 минут  
**Решение:**
1. Оптимизируйте размер файла (720p достаточно)
2. Убедитесь, что длительность 15-60 секунд
3. Проверьте интернет соединение
