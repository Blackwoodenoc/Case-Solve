# 🚀 Instagram Downloader с V2Ray прокси

## 📝 Инструкция по настройке

### Шаг 1: Установите V2Ray клиент

**Рекомендуется: v2rayN (GUI)**
1. Скачайте: https://github.com/2dust/v2rayN/releases/latest
2. Выберите: `v2rayN-windows-64.zip` (с Core)
3. Распакуйте в любую папку

### Шаг 2: Добавьте ваш сервер

1. Запустите `v2rayN.exe`
2. Скопируйте вашу ссылку:
```
vless://383c9935-60eb-4167-ba81-8ebff27b2a90@146.0.72.69:443/?type=tcp&encryption=none&flow=xtls-rprx-vision&sni=google.com&fp=chrome&security=reality&pbk=4rbu-4szdKKZyoGEhLwA_5tqjjAFYtEL5OvQDHCY3Q0&sid=325f371a0a47#sigma-krutoy-sigma
```
3. В v2rayN: **Servers** → **Import URL from Clipboard**
4. Нажмите **Enter**

### Шаг 3: Настройте локальные порты

1. **Settings** → **Core: Routing settings** 
2. Убедитесь что порты:
   - **Socks Port**: `10808`
   - **HTTP Port**: `10809`

### Шаг 4: Включите прокси

1. ПКМ на иконке v2rayN в трее
2. **System Proxy** → **Clear system proxy** (НЕ включайте системный прокси!)
3. Просто убедитесь что v2rayN **запущен** (статус: зелёный)

### Шаг 5: Проверка

Запустите тест:
```bash
python download_instagram_proxy.py "https://www.instagram.com/reel/DCUBzY0yiKK/" "temp_videos"
```

## 💡 Почему это работает?

- **V2Ray** с **REALITY** протоколом маскируется под HTTPS к Google
- Instagram не может определить что это прокси
- Ваш IP меняется на `146.0.72.69`
- **Нет rate limiting** - чистая репутация нового IP

## ⚡ Быстрый старт (всё в одном)

1. Скачайте v2rayN: https://github.com/2dust/v2rayN/releases/latest
2. Запустите → Import URL → вставьте вашу vless ссылку
3. Убедитесь что v2rayN запущен (зелёный статус)
4. Всё! Приложение автоматически обнаружит прокси
