# 🚀 Быстрый старт

## Установка и запуск

### 1. Установите зависимости
```bash
npm install
```

### 2. Запустите приложение

#### Вариант 1: Запустить всё сразу (рекомендуется)
```bash
npm run dev:all
```
Это запустит и фронтенд (Vite), и бэкенд (Express) одновременно.

#### Вариант 2: Запустить отдельно

**Терминал 1 - Фронтенд:**
```bash
npm run dev
```

**Терминал 2 - Бэкенд:**
```bash
npm run dev:server
```

### 3. Откройте браузер
- Фронтенд: http://localhost:3000 (или другой порт, указанный Vite)
- Бэкенд API: http://localhost:3003

## ⚠️ Решение ошибки "Failed to fetch"

Если вы видите ошибку **"Failed to fetch"** или **"Не удалось подключиться к серверу"**, это означает, что бэкенд сервер не запущен.

### Решение:
1. Убедитесь, что сервер запущен на порту 3003
2. Откройте новый терминал и выполните:
   ```bash
   npm run dev:server
   ```
3. Дождитесь сообщения: `🚀 API сервер запущен на http://localhost:${PORT}`
4. Обновите страницу в браузере

### Проверка, что сервер работает:
Откройте в браузере: http://localhost:3003/health

Вы должны увидеть JSON с информацией о состоянии сервера.

## 📋 Требования

- Node.js 18+ 
- Python 3.8+ (для yt-dlp, Whisper)
- yt-dlp установлен: `pip install yt-dlp`
