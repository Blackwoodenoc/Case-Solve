# VideoMind AI — глубокая видеоаналитика с анализом ДНК Shorts

Платформа для анализа видео на базе ИИ со специализированным модулем **Shorts DNA Analysis** для разборки вирусного короткого контента (Shorts/Reels/TikTok).

## ✨ Возможности

### 🎬 Стандартный анализ видео

* **Суммаризация контента**: извлечение ключевых мыслей и инсайтов
* **Глубокий анализ**: обнаружение объектов, людей и действий с таймкодами
* **Техническое извлечение**: извлечение фрагментов кода и технического текста из видео
* **Поддержка ссылок**: анализ ссылок Instagram/TikTok/YouTube с обогащением метаданными

### 🧬 **НОВОЕ: Анализ ДНК Shorts**

Разбор коротких видео и извлечение «ДНК успеха»:

* **Разбор структуры** с таймкодами (Хук → Подводка → Основная часть → Кульминация → CTA)
* **Паттерны удержания** (хуки, клиффхэнгеры, «открытые петли»)
* **Анализ Tone of Voice** (архетип, настроение, формальность, фирменные фразы)
* **Темп речи** (оценка WPM, метка темпа, стиль пауз)
* **Визуальный стиль** (монтаж, типы кадров, текст на экране)
* **Правила генерации** (8–15 практических правил для воспроизведения стиля)

Результат: красивый интерактивный **Style Passport** в формате JSON

### 🔍 Расширенные возможности

* **Привязка к Google Search (Grounding)**: проверка метрик постов в соцсетях
* **Обогащение метаданных**: интеграция OEmbed для более точного анализа
* **Поддержка разных форматов**: загрузка файлов или вставка URL
* **Экспорт**: копирование или скачивание результатов анализа

## 🚀 Запуск локально

**Требования:**

* Node.js
* Python 3.8+
* `yt-dlp` (установить через `pip install yt-dlp` или скачать из [релизов GitHub](https://github.com/yt-dlp/yt-dlp/releases))

> 📖 **Подробная инструкция по установке yt-dlp:** см. [docs/YT-DLP_SETUP.md](docs/YT-DLP_SETUP.md)

1. Установите зависимости Node.js:

   ```bash
   npm install
   ```

2. Установите зависимости Python:

   ```bash
   pip install yt-dlp instaloader selenium requests
   ```

3. Укажите `GEMINI_API_KEY` в файле `.env`:

   ```env
   GEMINI_API_KEY=your_api_key_here
   ```

4. Запустите приложение:

   ```bash
   npm run dev:all
   ```

   Это запустит фронтенд (порт 3000) и бэкенд (порт 3003).

📖 **Подробная инструкция по установке:** см. [docs/INSTALL_DEPENDENCIES.md](docs/INSTALL_DEPENDENCIES.md)

4. Откройте [http://localhost:5173](http://localhost:5173) в браузере

## 🧬 Как работает анализ ДНК Shorts

1. **Скачайте видео** с YouTube (опционально, см. [docs/DOWNLOAD_VIDEO.md](docs/DOWNLOAD_VIDEO.md))
2. **Загрузите** короткий видеофайл (рекомендуется 15–60 секунд, MP4/MOV/WEBM)
3. Нажмите **«🧬 Анализ ДНК Shorts»** (Shorts DNA Analysis)
4. Дождитесь обработки ИИ — **все кадры анализируются последовательно** (а не только ключевые!)
5. Изучите интерактивный просмотрщик **Style Passport**
6. **Скопируйте или скачайте** JSON для использования в других инструментах

> ⚠️ **Важно**: анализ обрабатывает **все кадры видео последовательно** для максимальной детализации, а не только key frames!

## ⚙️ Конфигурация

Приложение использует Gemini API с двумя моделями:

* **Gemini 2.5 Flash** — для анализа видео/аудио (Shorts DNA)
* **Gemini 3 Pro** с Google Search — для анализа ссылок (remote link analysis)

Для полной функциональности нужен **платный ключ GCP API**.
