# 🧬 Shorts DNA Analysis Integration

## Обзор

В приложение VideoMind AI добавлен новый режим анализа: **Shorts DNA Analysis** — специализированный AI-аналитик для деконструкции коротких видео (Shorts/Reels/TikTok) с извлечением «ДНК успеха» и генерацией структурированного «паспорта стиля» автора.

## ✨ Новые возможности

### 1. Анализ паттернов удержания
- Типы крючков (вопрос, обещание, шок, конфликт, личная история, цифры, ошибка)
- Темп речи и паузы
- «Открытые петли» и клиффхэнгеры
- Повторяющиеся приёмы (списки, контраст, "до/после", миф/правда)

### 2. Структура видео с таймкодами
- **Hook** (завязка) — первые секунды
- **Setup** (настройка контекста)
- **Main** (основная часть)
- **Climax** (кульминация)
- **CTA** (призыв к действию)

### 3. Tone of Voice
- Архетип автора
- Настроение (агрессивно/иронично/познавательно/дружелюбно)
- Уровень формальности (0-10)
- Коронные фразы и обращения к зрителю
- Фразы-паразиты и типичные связки

### 4. Скорость речи
- WPM (слов в минуту)
- Оценка темпа (low/medium/high)
- Стиль пауз

### 5. Визуальный стиль
- Статика/динамика монтажа
- Типы кадров
- Стиль текста на экране
- Типичные действия

### 6. Правила имитации
- 8-15 конкретных исполняемых правил для генерации нового контента в том же стиле

## 🚀 Использование

1. **Загрузите короткое видео** (Shorts/Reels/TikTok) через файл (не URL)
2. Нажмите **"🧬 Shorts DNA Analysis"**
3. Дождитесь завершения анализа
4. Изучите паспорт стиля в интерактивном интерфейсе
5. Скопируйте или скачайте JSON для использования в других системах

## ⚙️ Технические детали

### Модель AI
- **Gemini 2.5 Flash** с нативной обработкой аудио и видео
- Temperature: 0.3 (для стабильности JSON)
- Автоматическое извлечение транскрипта из аудиодорожки
- Покадровый анализ визуального ряда

### Обработка ответа
Функция автоматически:
1. Удаляет markdown обёртки (```json) если модель их добавила
2. Парсит JSON
3. Валидирует структуру
4. Возвращает структурированный объект или текст ошибки

### Ограничения
- Доступно только для **локальных файлов** (не URL)
- Требуется API ключ от платного GCP проекта
- Оптимизировано для видео длительностью 15-60 секунд

## 🔮 Применение

Полученный паспорт стиля можно использовать для:
1. **Генерации новых сценариев** в том же стиле (промпт для GPT/Claude)
2. **Обучения команды** — шаблон успешного контента
3. **A/B тестирования** — сравнение разных стилей
4. **Конкурентного анализа** — изучение чужих паттернов
5. **Автоматизации** — API интеграция для массового анализа
