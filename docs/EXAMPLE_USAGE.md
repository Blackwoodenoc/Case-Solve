## 📝 Промпт для генерации нового сценария

```
Создай сценарий для YouTube Shorts на тему "Почему утренние тренировки эффективнее вечерних".

ОБЯЗАТЕЛЬНЫЕ ТРЕБОВАНИЯ (Style Passport v1.0):

TONE OF VOICE:
- Архетип: Уверенный эксперт-разоблачитель
- Настроение: энергично, иронично, познавательно
- Формальность: 4/10 (ты-обращение, простой язык)
- Коронные фразы: "А теперь самое интересное", "И вот что реально работает", "Запомните это"
- Обращения: "ты", "друзья", "смотрите"

ТЕМП:
- 180-200 слов в минуту (быстро)
- Короткие драматические паузы 0.5 сек перед важными утверждениями
- Jump cuts каждые 2-3 секунды

СТРУКТУРА (60 секунд):

[00:00-00:04] HOOK
- Начни с шокирующей цифры или провокационного вопроса
- Пример: "95% людей тренируются неправильно. И вот почему..."
- Обязательно обещай конкретную пользу

[00:04-00:12] SETUP  
- Опровергни распространённый миф за 8 секунд
- Используй конструкцию: "Все думают [миф], но на самом деле [правда]"
- Создай когнитивный диссонанс

[00:12-00:42] MAIN (30 сек)
- Ровно 3 факта с явной нумерацией: "ПЕРВОЕ", "ВТОРОЕ", "ТРЕТЬЕ"
- Каждый факт 8-10 секунд
- Между фактами микропаузы 0.5 сек
- На 15-й и 35-й секунде добавь "открытую петлю": "но это ещё не всё", "сейчас главное"

[00:42-00:52] CLIMAX (10 сек)
- Начни с фразы: "А теперь самое интересное" или "И вот что реально работает"
- Дай неожиданный инсайт или главный вывод
- Используй контраст: "Вы думали [X], но правда — [Y]"

[00:52-00:60] CTA (8 сек)
- Призыв: "Подпишись, если хочешь больше таких фактов"
- Тизер: "В следующем видео расскажу про [следующая тема]"

ПАТТЕРНЫ УДЕРЖАНИЯ:
1. Открытые петли перед каждым ключевым блоком: "но", "однако", "самое важное"
2. Контрасты МИФ vs ПРАВДА минимум 2 раза (в setup и climax)
3. Нумерация в main части для создания ожидания завершения

ВИЗУАЛЬНЫЕ УКАЗАНИЯ:
- Крупный план лица на протяжении 90% времени
- Зумы на важных моментах (факты, инсайт)
- Жёлтый текст с чёрной обводкой для цифр и ключевых слов
- Жесты: указательный палец на списках, открытые ладони на выводах

DO:
✓ Начинай с цифры/вопроса в первые 2 секунды
✓ Держи темп 180-200 WPM
✓ Добавляй ключевые слова на экран
✓ Варьируй интонацию

DON'T:
✗ Не используй длинные вступления
✗ Не говори монотонно
✗ Не делай видео длиннее 60 сек
✗ Не забывай CTA

ФОРМАТ ВЫХОДА:
Выдай сценарий в виде таблицы с колонками:
| Время | Текст | Визуал | Текст на экране | Жесты |
```

## 🔄 Итерация и улучшение

После генерации можно:
1. **Проверить соответствие** паспорту (все ли правила соблюдены)
2. **Сравнить WPM** (посчитать слова, разделить на время)
3. **Протестировать** на фокус-группе
4. **Обновить паспорт** на основе метрик (retention rate, watch time)

## 🤖 Автоматизация

Можно создать скрипт:

```typescript
async function generateShortScript(topic: string, passportPath: string) {
  const passport = JSON.parse(fs.readFileSync(passportPath, 'utf-8'));
  
  const prompt = buildPromptFromPassport(passport, topic);
  const script = await callLLM(prompt);
  
  // Валидация
  const validation = validateScriptAgainstPassport(script, passport);
  if (!validation.passed) {
    console.warn("Нарушены правила:", validation.violations);
  }
  
  return script;
}
```

## 📊 Метрики успеха

После публикации сравни:
- **AVD** (Average View Duration) — должен быть >50% для Shorts
- **CTR** — thumbnail и hook работают?
- **Retention graph** — где проседает удержание?
- **Комментарии** — какие фразы цитируют?
