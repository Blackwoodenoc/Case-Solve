# 🚀 Настройка yt-dlp для скачивания видео

## 📥 Установка yt-dlp

### Способ 1: Через pip (рекомендуется)

```bash
pip install yt-dlp
```

### Способ 2: Скачать бинарник (Windows)

1. Перейдите на https://github.com/yt-dlp/yt-dlp/releases
2. Скачайте `yt-dlp.exe` (для Windows)
3. Поместите файл в папку, которая есть в PATH, или в папку проекта

### Способ 3: Скачать архив с yt-dlp + ffmpeg

1. Найдите готовый архив с yt-dlp и ffmpeg (например, на форумах)
2. Распакуйте в любую папку
3. Добавьте папку в PATH или используйте полный путь

## ✅ Проверка установки

### В командной строке:

```bash
yt-dlp --version
```

Если команда не найдена, попробуйте:

```bash
python -m yt_dlp --version
```

### Через приложение:

Откройте в браузере: `http://localhost:3003/health`

Должен вернуться JSON с информацией о yt-dlp:

```json
{
  "status": "OK",
  "service": "VideoMind API",
  "ytdlp": {
    "available": true,
    "method": "system",
    "version": "2025.01.07"
  }
}
```

## 📋 Основные команды yt-dlp

### Обновление до последней версии

```bash
yt-dlp -U
```

### Просмотр доступных форматов

```bash
yt-dlp -F "URL_видео"
```

### Скачивание в максимальном качестве

```bash
yt-dlp "URL_видео"
```

### Скачивание в определенном качестве

```bash
yt-dlp -f "best[ext=mp4][height<=720]" "URL_видео"
```

### Скачивание только аудио

```bash
yt-dlp -x --audio-format mp3 "URL_видео"
```

## 🔧 Решение проблем

### "yt-dlp не найден"

1. Убедитесь, что yt-dlp установлен: `pip install yt-dlp`
2. Проверьте PATH: `where yt-dlp` (Windows) или `which yt-dlp` (Linux/Mac)
3. Если не работает, используйте: `python -m yt_dlp` вместо `yt-dlp`

### "Видео не скачивается"

1. Обновите yt-dlp: `yt-dlp -U`
2. Проверьте, что ссылка корректна
3. Видео может быть приватным или удалено

### "Ошибка при скачивании с Instagram"

- Убедитесь, что это публичный пост/Reels
- Проверьте, что в посте есть видео (не фото)
- Для приватных аккаунтов используйте публичные ссылки

## 💡 Советы

1. **Регулярно обновляйте**: `yt-dlp -U` - это решает 95% проблем
2. **Используйте максимальное качество**: по умолчанию yt-dlp скачивает лучшее качество
3. **Для плейлистов**: просто укажите ссылку на плейлист, yt-dlp скачает все видео
4. **Субтитры**: добавьте `--write-subs --sub-langs ru,en` для скачивания субтитров
