# 🔥 Использование топ залайканных комментариев

## ✅ Что реализовано

Все эндпоинты теперь автоматически сортируют комментарии по лайкам и возвращают топ комментарии!

### YouTube
- ✅ Автоматическая сортировка по лайкам
- ✅ Возвращает `top_comments` (топ-20)
- ✅ Логирует топ-5 в консоль для проверки

### Instagram
- ✅ Автоматическая сортировка по лайкам в скрипте
- ✅ Возвращает `top_comments` (топ-20)
- ✅ Логирует топ-5 в консоль

### TikTok
- ✅ Автоматическая сортировка по лайкам в скрипте
- ✅ Возвращает `top_comments` (топ-20)
- ✅ Логирует топ-5 в консоль

---

## 📡 Использование

### Универсальный эндпоинт для топ комментариев

```javascript
POST /api/top-comments
Body: {
  "url": "https://...",
  "topCount": 20  // Количество топ комментариев (по умолчанию 20)
}
```

**Ответ:**
```json
{
  "success": true,
  "platform": "youtube",
  "video_id": "...",
  "count": 20,
  "top_comments": [
    {
      "id": "...",
      "author": "username",
      "text": "Текст комментария",
      "like_count": 1500,
      "reply_count": 10,
      "published_at": "...",
      "is_pinned": false
    }
  ],
  "total_comments_found": 500,
  "sorted_by": "likes"
}
```

### Прямые эндпоинты (тоже возвращают топ)

Все эндпоинты теперь автоматически сортируют по лайкам:

```javascript
// YouTube
POST /api/youtube-comments
Body: { "url": "https://www.youtube.com/watch?v=..." }

// Instagram
POST /api/instagram-comments
Body: { "url": "https://www.instagram.com/reel/..." }

// TikTok
POST /api/tiktok-comments
Body: { "url": "https://www.tiktok.com/@username/video/..." }
```

**Все возвращают:**
- `comments` - все комментарии (отсортированы по лайкам)
- `top_comments` - топ-20 комментариев
- `sorted_by: "likes"` - информация о сортировке

---

## 🔍 Проверка в консоли

Все эндпоинты логируют топ-5 комментариев в консоль сервера:

```
🔥 Топ-5 комментариев по лайкам:
  1. username1: Текст комментария... (1500 лайков)
  2. username2: Другой комментарий... (1200 лайков)
  3. username3: Еще один... (800 лайков)
  4. username4: И еще... (500 лайков)
  5. username5: Последний... (300 лайков)
```

Это помогает быстро проверить, что комментарии извлекаются правильно!

---

## 🎯 Преимущества

1. **Быстрая проверка** - видите топ комментарии сразу в консоли
2. **Надежность** - если извлекаются хотя бы топ комментарии, значит метод работает
3. **Удобство** - не нужно искать среди всех комментариев самые залайканные
4. **Автоматическая сортировка** - все комментарии уже отсортированы по лайкам

---

## 📊 Пример использования

```bash
# Получить топ-10 комментариев
curl -X POST http://localhost:3003/api/top-comments \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://www.youtube.com/watch?v=...",
    "topCount": 10
  }'
```

---

## ⚠️ Если комментарии не извлекаются

1. **Проверьте логи сервера** - там будут топ-5 комментариев, если они извлеклись
2. **Проверьте ошибки** - в ответе будет поле `error` с описанием проблемы
3. **Попробуйте другой URL** - возможно, у этого видео комментарии отключены
4. **Проверьте зависимости** - убедитесь, что все библиотеки установлены

---

## 🔄 Что делать дальше

Если основной метод не работает:
1. Проверьте логи - возможно, комментарии извлекаются, но есть ошибка парсинга
2. Попробуйте fallback варианты из `docs/COMMENTS_FALLBACK.md`
3. Используйте топ комментарии для проверки - если они есть, значит метод работает!
