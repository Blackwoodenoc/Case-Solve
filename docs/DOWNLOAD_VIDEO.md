# 📥 Инструкция: Как скачать видео с YouTube и Instagram для анализа

## 🚀 Автоматическая загрузка через приложение

Приложение автоматически скачивает видео с **YouTube** и **Instagram** используя `yt-dlp`.

### Шаг 1: Установите yt-dlp

**Вариант 1 (рекомендуется):**
```bash
pip install yt-dlp
```

**Вариант 2 (Windows - бинарник):**
1. Скачайте `yt-dlp.exe` с https://github.com/yt-dlp/yt-dlp/releases
2. Поместите в папку проекта или добавьте в PATH

> 📖 **Подробная инструкция:** [YT-DLP_SETUP.md](YT-DLP_SETUP.md)

### Шаг 2: Используйте приложение

1. Откройте http://localhost:5173/
2. Вставьте ссылку на видео (YouTube или Instagram)
3. Нажмите "Загрузить по ссылке"
4. Видео автоматически скачается и загрузится
5. Нажмите "🧬 Анализ ДНК Shorts"

### Поддерживаемые ссылки:

- ✅ **YouTube**: `https://www.youtube.com/watch?v=...` или `https://youtube.com/shorts/...`
- ✅ **Instagram Reels**: `https://www.instagram.com/reel/...`
- ✅ **Instagram посты с видео**: `https://www.instagram.com/p/...`

---

## 🌐 Альтернативные способы (если автоматическая загрузка не работает)

### Способ 1: Командная строка (yt-dlp напрямую)

```bash
# Установка
pip install yt-dlp

# YouTube
yt-dlp -f "best[ext=mp4][height<=720]" https://youtube.com/shorts/n3MDC60tUGo

# Instagram Reels
yt-dlp -f "best[ext=mp4]" https://www.instagram.com/reel/ABC123/

# С указанием папки
yt-dlp -f "best[ext=mp4]" -o "downloads/%(title)s.%(ext)s" <URL>
```

### Способ 2: Онлайн сервисы

1. **y2mate.com** - для YouTube
2. **savefrom.net** - для YouTube
3. **snapinsta.app** - для Instagram

### Способ 3: Браузерные расширения

- **Video DownloadHelper** (Firefox/Chrome)
- **YouTube Downloader** (различные)

## ⚠️ Важные замечания

1. **Длина видео**: Для лучшего анализа используйте видео 15-60 секунд (Shorts/Reels)
2. **Качество**: Достаточно 720p, не обязательно 4K
3. **Размер файла**: Видео >100MB могут загружаться медленнее
4. **Авторские права**: Скачивайте только для личного анализа

## ❓ Проблемы?

### "yt-dlp не найден"
```bash
pip install --upgrade yt-dlp
```

### "Ошибка скачивания с YouTube"
- Проверьте интернет соединение
- Убедитесь, что ссылка корректна
- Попробуйте другую ссылку
- Видео может быть приватным или удалено

### "Ошибка скачивания с Instagram"
- Убедитесь, что это публичный пост/Reels
- Проверьте, что в посте есть видео (не фото)
- Для приватных аккаунтов используйте публичные ссылки
- Попробуйте ссылку на Reels: `https://www.instagram.com/reel/...`

### "Видео слишком большое"
Приложение автоматически ограничивает размер до 150MB. Для ручной загрузки:
```bash
yt-dlp -f "best[filesize<50M]" <URL>
```

### "Это Instagram пост с фото, а не видео"
Используйте ссылку на **Instagram Reels** (видео), а не обычный пост с фото.
